-Hanoi tower solver:
Certification project for FreeCodeCamp, written September 12th, 2026;

Learned and applied recursive programming in python, at first I took the time to learn the game myself and realized that 
you have a source, spare, and target stack that alternate positions, with each function call you enter a part of the 'position tree' and 
set the source, spare, and target rods to A,B,C or A,C,B ... so on; (I designated them A,B,C from left to right) 
Realized completing a substack of size n and going back to the call stack will set back A,B,C to their previous source, spare, target designations, 
swapping disks until the tower is solved
